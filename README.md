# AI-Based Fake News Detection Using Machine Learning

## 📌 Project Overview

This project is an AI-based Fake News Detection System that uses Machine Learning to identify whether a news article is **Real** or **Fake**.

The system analyzes the text of a news article and predicts its category using Natural Language Processing (NLP) and Machine Learning techniques.

## 🎯 Objectives

- Detect fake and real news automatically
- Reduce the spread of misleading information
- Apply Machine Learning for text classification
- Provide a simple and user-friendly news prediction system

## 🛠️ Technologies Used

- Python
- Machine Learning
- Natural Language Processing (NLP)
- Scikit-learn
- Pandas
- Streamlit

## ⚙️ How It Works

1. News data is collected and prepared.
2. The text data is cleaned and processed.
3. Text features are extracted using NLP techniques.
4. A Machine Learning model is trained using real and fake news data.
5. The trained model predicts whether new news is Real or Fake.
6. The result is displayed to the user.

## 📂 Project Files

- `app.py` – Main application
- `create_dataset.py` – Dataset creation/preparation
- `news detection system.py` – News detection logic
- `fake_news_1000.csv` – Fake news dataset
- `real_news_1000.csv` – Real news dataset

## 🚀 Features

- Real/Fake news classification
- Machine Learning based prediction
- Text-based analysis
- Simple user interface
- Dataset-based model training
